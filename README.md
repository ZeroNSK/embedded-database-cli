# Embedded Database CLI

**Прежнее название репозитория:** `3Sem1Practice`.

Учебная файловая база данных на C++ с командным интерфейсом, собственными структурами данных и сохранением состояния в JSON.

**Примерный период реализации:** декабрь 2025. Период указан по истории Git и отражает основную работу над проектом.

## Возможности

Хранение множеств, стеков, очередей, хеш-таблиц и деревьев. Команда передаётся через `--query`, путь к JSON-файлу — через `--file`.

## Сборка и пример

Требуется компилятор C++17 и Make; JSON-библиотека включена в репозиторий.

```bash
make
./program --file db.json --query "SADD users alice"
```

Сетевая версия находится в отдельном проекте [Network Database Server](https://github.com/ZeroNSK/network-database-server).
